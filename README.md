# Hệ thống thu thập, so sánh và gợi ý sản phẩm TMĐT

## Yêu cầu môi trường
- Docker
- Docker Compose

## Cách chạy hệ thống

### 1. Clone source code
```bash
git clone <repo-url>
cd <project-name>
```

### 2. Khởi động hệ thống
```bash
docker compose up --build
```

## Truy cập hệ thống
- Frontend: http://localhost:5173
- Backend API: http://localhost:8000
